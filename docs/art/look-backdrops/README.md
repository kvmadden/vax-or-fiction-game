# Look backdrops

`public/look-art/<look>-stage.webp` and `<look>-phone.webp` are the backdrops of the three drawn looks: Studio set
(`studio`), Case file (`casefile`) and 70s game show (`seventies`). Generated with Gemini image generation on 2026-10-01
and 2026-10-02, one big-screen and one phone picture per look, and converted to WebP. `src/looks/look.ts` is the one
place that builds their paths.
